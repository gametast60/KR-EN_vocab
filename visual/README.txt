วิธีเพิ่มคำศัพท์สำหรับ Stage 1–5 (ข้อมูลต้นฉบับจุดเดียวต่อระดับ)

เปิด VocabularyStudio/Start.bat เพื่อเตรียมคำ ตัดภาพ และแก้ข้อมูลในโปรแกรมเดียว
อ่านวิธีใช้ใน VocabularyStudio/docs/USER_GUIDE.md
โปรแกรมไม่ใช้ AI/API คำที่ต้องคิดเรื่องภาษาเก็บใน VocabularyStudio/data/review_queue.json
ตาราง VocabularyStudio/data/vocabulary_map.md ใช้นำเข้าชุดภาพที่ทำไว้แล้ว ไม่ใช่ไฟล์ที่แอปอ่านโดยตรง
ขั้นตอนด้านล่างเป็นข้อมูลอ้างอิงสำหรับแก้ข้อมูลด้วยตนเอง

1. เลือกไฟล์ระดับที่จะเพิ่มหรือแก้รายการ
   TOPIK 1: flashcard1.js
   TOPIK 2: flashcard2.js
   English A1: flashcard_en_a1.js
   English A2: flashcard_en_a2.js
   English B1: flashcard_en_b1.js
   English B2: flashcard_en_b2.js

2. วางภาพใน visual/images เช่น 0021.webp แล้วเพิ่มข้อมูลในรายการคำศัพท์เดียวกัน
   ตัวอย่างรูปแบบ (อย่าเพิ่มคำซ้ำหากมีคำนี้แล้ว ให้แก้รายการเดิม):
   {
     word: "가다",
     meaning: "ไป",
     imageId: "0006",
     sentense: "저는 내일 학교에 갑니다.",
     translate: "พรุ่งนี้ฉันไปโรงเรียน",
     sentenceAnswer: "갑니다"
   }

   Stage 1–3 ใช้ word, meaning, imageId
   Stage 4–5 ใช้ sentense (หรือ sentence), translate และ sentenceAnswer
   ไม่มีประโยค: ไม่ต้องใส่ sentense, translate, sentenceAnswer ระบบจะข้าม Stage 4–5
   มีประโยคแต่ยังไม่ตรวจคำตอบ: เว้น sentenceAnswer ไว้ก่อน
   ไม่มีภาพแต่มีประโยคและคำตอบ: ใช้ได้ในแบบฝึก Stage 5 เดี่ยว
   sentenceAnswer ต้องเป็นข้อความที่ต้องการเว้นช่องว่างในประโยคจริง รวมรูปผันตามบริบท
   ระบุ sentenceAnswer ถือว่าผู้จัดทำตรวจแล้วว่าคำนั้นสื่อความหมายเป้าหมาย
   ถ้าคำตอบปรากฏซ้ำ ให้ระบุ sentenceOccurrence: 2 เพื่อเลือกครั้งที่สอง (เริ่มนับจาก 1)
   ถ้าประโยคเปลี่ยน ต้องตรวจ sentenceAnswer อีกครั้ง ระบบตรวจตำแหน่งได้แต่ไม่ตัดสินความหมายแทนผู้จัดทำ

3. ใช้ภาพร่วมกันระหว่างภาษาได้ด้วย imageId เดียวกัน
   ตัวอย่างรายการอังกฤษ: { word: "go", meaning: "ไป", imageId: "0006" }
   ไม่ต้องเพิ่มประโยคอังกฤษหากยังไม่มี และไม่ต้องสร้างไฟล์ภาพซ้ำ
   imageId ต้องเป็นข้อความมีเลขอย่างน้อย 4 หลัก เช่น "0006" ไม่ใช่เลข 6
   PNG ให้เพิ่ม imageExtension: "png" (ค่าเริ่มต้นคือ webp)
   รหัสภาพเดียวกันต้องใช้ชนิดไฟล์เดียวกันทุกระดับ
   displayWord: ใช้ระบุคำที่แสดง/อ่าน/พิมพ์ เช่น word: "light (not heavy)", displayWord: "light"
   sentenceAcceptedAnswers: อาร์เรย์คำตอบอื่นที่ตรวจแล้ว เช่น ["..."] (ไม่จำเป็นต้องใส่)

4. ตรวจข้อมูลด้วยคำสั่งจากโฟลเดอร์โปรเจกต์
   node tools/check-vocabulary.cjs
   คำสั่งนี้อ่านอย่างเดียว ตรวจคำซ้ำ รูปแบบข้อมูล คำตอบ และไฟล์ภาพที่ขาด
   WARN แสดงข้อผิดรูปแบบในคลังคำศัพท์เดิม; ERROR แสดงข้อผิดพลาดการเชื่อม Stage 1–5
   ก่อนเผยแพร่ควรตรวจข้อความเตือนทั้งหมด รายการกำกวมจะไม่ถูกใช้ในโหมดใหม่
   node --test tests/*.test.cjs

ไม่ต้องแก้ sentence-exercises.js, image-map.js หรือรายการภาพใน sw.js อีก
vocabulary-catalog.js สร้างข้อมูลให้เกมจากไฟล์ทั้ง 6 ระดับโดยอัตโนมัติ ไม่ใช่ไฟล์สำหรับกรอกคำศัพท์
sw.js อ่านภาพที่อ้างอิงทั้งหมดและแยกแคชตามข้อมูลคำศัพท์ เมื่อเผยแพร่ไฟล์ที่แก้และภาพใหม่พร้อมกัน
ให้รีโหลดแอปหลังอัปเดตเพื่อรับเวอร์ชันใหม่ตามวงจร service worker
ไฟล์ภาพที่เปลี่ยนเนื้อหาโดยใช้ชื่อเดิม ควรใช้รหัสภาพใหม่หรือเพิ่มเวอร์ชันแคชใน sw.js

ผลการเรียน Visual Recall อยู่เฉพาะรอบปัจจุบัน ไม่แก้โครงสร้าง SRS หรือข้อมูลความคืบหน้าเดิม

Stage 4 เรียนประโยค: แสดงคำฐาน → รูปคำในประโยค เน้นคำเป้าหมาย อ่านคำฐาน รูปคำ และประโยคเต็มตามลำดับ
Stage 5 เติมคำ: ใช้ประโยคและคำตอบเดียวกับที่เรียน ไม่ต้องเพิ่มข้อมูลอีกชุด
เรียนแบบทีละชุดทุกด่าน ไม่มีประโยคพร้อมใช้จะข้ามทั้ง Stage 4–5
