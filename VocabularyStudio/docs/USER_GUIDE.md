# Vocabulary Studio — โปรแกรมเดียวสำหรับคลังภาพและคำศัพท์

เปิด `VocabularyStudio/Start.bat` (ตัวเปิดโปรแกรมเพียงไฟล์เดียว) ใช้ Python + Tkinter + Pillow และ Node.js ที่ติดตั้งในเครื่อง ไม่ใช้ API/โทเค็น และไม่ติดตั้งอะไรอัตโนมัติ

## ตรวจและบันทึกชุดงาน

1. เปิดแท็บ **3 ตรวจและบันทึก** เลือกช่วงใน **ชุดที่บันทึก** แล้วกด **เปิดชุดที่เลือก** หรือกด **เปิดงานภาพค้าง** เพื่อทำชุดที่บันทึกภาพแล้วต่อ
2. ตรวจภาพกับคำศัพท์แล้วกด **1. ยืนยันภาพทั้งชุด** ใช้ความหมายเดิมของคำศัพท์ ไม่เพิ่มฟิลด์ความหมายภาพลงคลัง
3. ตรวจคำตอบและคำแปลในตาราง แล้วกด **2. ยืนยันคำตอบที่กรอกแล้ว** ครั้งเดียว โปรแกรมข้ามคำตอบที่ว่าง ข้อมูลไม่ครบ หรือไม่ตรงตำแหน่งในประโยค
4. แถวที่ยังไม่มีคำตอบ: เลือกแถว → ลากเลือกข้อความในประโยค → **ใช้ข้อความที่เลือกเป็นคำตอบ** → ติ๊ก **ยืนยันคำตอบและคำแปล** แก้ประโยคและคำแปลในหน้านี้ได้
5. กด **3. ตรวจและบันทึกชุดนี้** โปรแกรมแสดงสรุปและตรวจข้อมูลก่อนเขียนต้นฉบับพร้อมสำรอง หากเลือกเพียงส่วนของคำกริยาจะให้ตรวจอีกครั้งก่อนบันทึก

การยืนยันทั้งชุดยังไม่เขียนไฟล์จนกดบันทึก ค่าที่แก้จะเก็บในชุดเมื่อเปลี่ยนแถว ปุ่มงานรอง เช่น ดูภาพ ดูโค้ด เปิด MD บันทึกแบบร่าง บันทึกแถวเดียว และย้อนกลับ อยู่ในเมนู **เพิ่มเติม ▾** คลิกขวาในช่องข้อความเพื่อคัดลอก/วาง

## ทำภาพชุดถัดไป

1. แท็บ **1 เตรียมคำ / พรอมป์ต์** เลือกระดับ → **โหลด 25 คำถัดไป** หรือ **วางโค้ด** คำต้องมีอยู่ในระดับที่เลือกและไม่ซ้ำ
2. ถ้าคำมีหลายความหมาย ตรวจว่าภาพและประโยคสื่อความหมายเดียวกัน โดยใช้ `meaning` เดิม ไม่ต้องเพิ่มฟิลด์พิเศษ
3. **คัดลอกพรอมป์ต์** ไป Gemini พร้อมภาพอ้างอิงที่ไม่มีข้อความ รายการที่ส่งมีเฉพาะคำศัพท์และความหมาย ไม่มีประโยค
4. **ส่งคำไป Cutter** แล้วเปิดภาพจาก Gemini ในแท็บ 2 ตารางตั้งเป็น 5 คอลัมน์ จำนวนแถวตามชุด ตรวจลำดับซ้ายไปขวา บนลงล่างและเส้นตัด
5. ตรวจเลขเริ่มต้น → **บันทึกภาพและไปตรวจคำศัพท์** โปรแกรมตัดภาพและบันทึกตรงลง `visual/images` พร้อมชุดงานค้าง แล้วเปิดหน้า 3 ไม่สร้าง ZIP / MD / CSV และไม่ต้องแตกไฟล์หรือคัดลอกภาพเอง
6. ตรวจและบันทึกตามขั้นตอนด้านบน ไม่ต้องคัดลอกรายการไป Cutter หรือแก้ JavaScript เอง

เลขเริ่มต้นใช้ค่าที่สูงกว่าระหว่างเลขภาพล่าสุด+1 กับเลขที่ Cutter จำหลัง Export เพื่อไม่ให้ชนชุดที่ยังไม่นำเข้า ตารางต้องมีจำนวนคำหาร 5 ลงตัว ถ้าชุดสุดท้ายไม่เต็มให้จัดชุดเองก่อนสร้างภาพ

## จับคู่ข้ามภาษา/ระดับ

เลือกแถวแล้วเปิด **เพิ่มเติม ▾ → จับคู่คำในระดับอื่น** โปรแกรมเสนอจากคำแปลไทยที่ตรงกัน สามารถพิมพ์คำอังกฤษ/เกาหลี/ความหมายเพื่อค้นทั้งหกระดับได้ เลือกคำที่ใช้ภาพเดียวกันจริงแล้วเพิ่มเป็นอีกแถว ตรวจยืนยันความหมายและคำตอบแยกกัน ใช้ความหมายภาพเดียวกันกับต้นทาง

ไม่พบคำ ไม่ได้หมายความว่าไม่มีคำในคลังเสมอไป เพราะคำแปลอาจใช้คนละข้อความ โปรแกรมไม่คิดคำใหม่เอง หากยังไม่จับคู่ข้ามภาษาจะเก็บงานไว้ในคิว สามารถนำคำใหม่ที่ GPT/Gemini เสนอกลับมาตรวจและบันทึกได้

## คิวงานภาษาและแบบร่าง

- คิวเดียว: `VocabularyStudio/data/review_queue.json` ใช้ระดับ+คำเป็นคีย์ อัปเดตแทนการสะสมซ้ำ เก็บเฉพาะบริบทจำเป็นและเหตุผลที่ค้าง
- แท็บ 4 แสดงคิว กด **เปิดคิวค้าง** ในแท็บ 3 เพื่อตรวจต่อ เมื่อแก้ครบแล้วบันทึก โปรแกรมเอางานที่ครบออกจากคิว
- ใช้ปุ่มคัดลอกคำสั่งในแท็บ 4 ส่งงานคิวให้แชทธรรมดาช่วยแต่งประโยค/เสนอคำใหม่ได้ครั้งละ 25 รายการ ไม่ต้องแนบไฟล์หรือภาพ และไม่ใช้ API ในโปรแกรม
- **บันทึกแบบร่าง** เก็บการตรวจที่ยังไม่ลงคลังสำหรับภาพที่อยู่ในโฟลเดอร์แล้ว หากไฟล์คลังเปลี่ยนภายหลังจะไม่เปิดแบบร่างเก่าทับงานใหม่
- ชุดที่นำเข้าจาก ZIP และยังไม่บันทึก ให้เก็บ ZIP ไว้ หากต้องหยุดสามารถบันทึกชุดพร้อมคิวโดยไม่ยืนยันรายการที่ยังไม่แน่ใจ แล้วกลับมาเปิดคิวภายหลัง
- คำที่มี imageId หรืออยู่ในคิวจะไม่ถูกปุ่มโหลดคำถัดไปเลือกมาสร้างภาพซ้ำ

## การตรวจและย้อนกลับ

- แก้ metadata ประโยคและคำแปลของรายการที่เลือกได้ ไม่ย้ายระดับหรือเปลี่ยน word/meaning ของคำเดิม เพิ่มคำใหม่ได้ผ่านผล JSON จากแชทที่ผ่านการตรวจและผู้ใช้ยืนยัน ไม่แก้กลไกแอพ
- หาก word ซ้ำในระดับเดียวกัน หรือไม่มีในคลัง จะไม่เดารายการเป้าหมาย
- พบ imageId เดิมคนละค่า หรือภาพใหม่ใช้ชื่อชนภาพเก่า จะไม่เขียนทับ
- แก้ไฟล์จากภายนอกหลังเปิดชุดงาน จะต้องโหลดใหม่ก่อนบันทึก
- สำรองแต่ละชุดอยู่ใน `VocabularyStudio/data/backups/` และมี journal สำหรับคืนค่าหากงานถูกขัดจังหวะ
- **ย้อนกลับชุดล่าสุด** คืนคลังและคิว ลบเฉพาะภาพที่โปรแกรมเพิ่งเพิ่มในชุดนั้น ภาพที่มีอยู่ก่อนชุดนั้นคงไว้ หากไฟล์ถูกแก้ต่อจากภายนอกจะไม่ย้อนทับ
- เก็บไฟล์สำรองไว้จนตรวจงานเสร็จ ใช้พื้นที่ดิสก์แต่ไม่กินโทเค็น AI ไม่ต้องอ่านโฟลเดอร์สำรอง
- ปิดหน้าต่างตัวช่วยรุ่นเก่าก่อนเปิดใหม่จาก VocabularyStudio/Start.bat ตัวเปิดซ้ำซ้อนถูกลบแล้ว โค้ด Cutter และตัวสร้างพรอมป์ต์อยู่ใน app/ เป็นส่วนประกอบของ Studio

ข้อจำกัด: แอพยังรองรับหนึ่งภาพต่อรายการคำศัพท์ ถ้าต้องเรียนหลายความหมายด้วยหลายภาพ ให้พักงานนั้นและขยายระบบแอพภายหลัง ห้ามสร้าง word ซ้ำเพื่อเลี่ยงข้อจำกัด

## โครงสร้างโฟลเดอร์

- `VocabularyStudio/Start.bat`: ไฟล์เดียวที่ต้องดับเบิลคลิก
- `VocabularyStudio/app/`: โค้ดโปรแกรมและแม่แบบพรอมป์ต์ ไม่ต้องเปิดเอง
- `VocabularyStudio/data/`: ตารางนำเข้า ค่า ID ถัดไป แบบร่าง คิวงานภาษา และสำรองข้อมูล
- `VocabularyStudio/docs/`: คู่มือและข้อความอ้างอิงเดิมของผู้ใช้
- `VocabularyStudio/tests/`: ชุดทดสอบของ Studio แยกจากการทดสอบแอพ
- `visual/images/`: ภาพที่แอพทวนศัพท์ใช้งานจริง จึงคงอยู่กับแอพ

อย่าย้าย VocabularyStudio ออกนอกโฟลเดอร์โปรเจกต์ เพราะโปรแกรมอ้างอิงคลัง flashcard ในโฟลเดอร์แม่
ทดสอบ Studio จากโฟลเดอร์โปรเจกต์: `python -m unittest discover -s VocabularyStudio/tests -p "test_vocab*.py"`

## แก้ประโยคในหน้าตรวจ

- ช่องประโยคและคำแปลไทยแก้ได้โดยตรง ไม่จำเป็นต้องเปิด JavaScript
- ลากเลือกคำหรือรูปผันในประโยคที่แก้ แล้วกด **ใช้ข้อความที่เลือกเป็นคำตอบ** จากนั้นตรวจและติ๊กยืนยันคำตอบและคำแปล
- เปลี่ยนแถวเพื่อเก็บค่าที่แก้ในชุดงาน หากต้องการบันทึกเฉพาะแถว เลือก **เพิ่มเติม ▾ → บันทึกแถวนี้ลงต้นฉบับ** พร้อมตรวจและสำรอง
- **ตรวจและบันทึกชุดนี้** บันทึกทุกรายการในตาราง
- เมื่อแก้ประโยคหรือคำแปล การยืนยันคำตอบจะถูกยกเลิกให้ตรวจใหม่ หากบันทึกโดยยังไม่ยืนยัน โปรแกรมจะเอา metadata คำตอบเก่าออกเพื่อไม่ให้โจทย์ผิด ใช้งานประโยคใหม่ได้หลังยืนยันคำตอบ
- ฟิลด์ประโยคเดิมชื่อ sentense จะถูกเก็บชื่อนี้ไว้ ไม่มีการเปลี่ยนชื่อฟิลด์ทั้งคลัง
- ช่องข้อความรองรับ Ctrl+C / Ctrl+V / Ctrl+X และคลิกขวาเพื่อคัดลอก วาง ตัด หรือเลือกทั้งหมด ช่องประโยครองรับ undo ด้วย Ctrl+Z

## คิวภาพร่วม: โปรแกรมค้น คุณเลือก แชทช่วยจัดข้อมูล

ตัวอย่าง: มีภาพ `집 / บ้าน` โปรแกรมค้นความหมายไทยในคลังอังกฤษ แล้วเสนอ `house` หรือ `home` ตามรายการที่มีจริง พร้อมระดับ คำแปล และ ID ภาพต้นทาง โปรแกรมไม่ใช้ AI และไม่เปิดอ่านภาพ

1. หลังบันทึกภาพ เปิดแท็บ **4 คิวงานภาษา** ที่หน้า **คำในคลังที่อาจใช้ภาพร่วมกัน**
2. กรองด้วยคำ ความหมาย หรือ ID ได้ รายการเป็นข้อเสนอจากคำแปลที่ตรงกัน ไม่ใช่การรับรองว่าใช้ภาพร่วมกันได้
3. คลิกเลือกคู่ที่คุณต้องการ ใช้ Ctrl/Shift เลือกหลายแถวได้ ถ้าคำเป้าหมายมีภาพอื่นอยู่แล้วจะแจ้งไว้และไม่สลับภาพให้เอง
4. กด **คัดลอกเฉพาะรายการที่เลือก** แล้ววางในแชท GPT/Gemini โปรแกรมส่งเพียงคำต้นทางกับคำคู่ที่คุณเลือก ไม่ให้แชทค้นคำพ้องเพิ่มหรือสร้างคำใหม่เอง
5. คัดลอก JSON จากแชท → **วางผลจากแชท** → **ดำเนินการ: ตรวจและเปิดตัวอย่าง**
6. โปรแกรมตรวจว่าคำที่ตอบกลับตรงกับคู่ที่เลือกไว้ แล้วเปิดขั้นตอน 3 ให้ตรวจประโยค ความหมาย และคำตอบ เลือก **เพิ่มเติม ▾ → ดูโค้ดก่อนบันทึก** ได้
7. ยืนยันแล้วบันทึก คำคู่จะใช้ ID ภาพเดียวกัน ไม่มีภาพสำเนาเพิ่ม คู่ที่ผูกแล้วจะไม่เสนอซ้ำ

**งานประโยค / ขอคำใหม่ที่เลือกเอง** เป็นอีกหน้าหนึ่งในแท็บ 4 สำหรับคิวภาษาที่เหลือ ต้องเลือกแถวเองก่อนคัดลอก หากต้องการให้แชทเสนอคำใหม่ ให้ติ๊ก **อนุญาตขอคำใหม่** อย่างชัดเจน โหมดนี้ไม่ใช่การจับคู่ภาพอัตโนมัติ

เลือกได้ไม่เกิน 25 คำต้นทางต่อคำสั่ง ถ้าคลังหรือคิวเปลี่ยนหลังคัดลอกคำสั่ง ต้องสร้างคำสั่งใหม่ โปรแกรมไม่ใช้ผลเก่าทับข้อมูลใหม่ และไม่เรียก GPT/Gemini เอง

## ตรวจคำตอบในประโยค

- ใต้ประโยคแสดง **ตัวอย่างโจทย์** ตามคำตอบและตำแหน่งที่เลือก เช่น `돈을 ［_____］고 있어요.` ทำให้เห็นว่าข้อสอบจะเว้นตรงไหน
- กริยา/คุณศัพท์เกาหลีที่เลือกเพียงส่วนของคำจะมีคำเตือน เช่น `가지` ใน `가지고` ให้ตรวจรูปที่ตั้งใจสอนก่อนยืนยัน การเตือนเป็นการตรวจขอบเขตข้อความ ไม่ใช่ตัวผันคำภาษาเกาหลี
- หากต้องการเว้นบางส่วนโดยตั้งใจ โปรแกรมให้ยืนยันข้อเตือนก่อนบันทึก ไม่แก้คำตอบเดิมของผู้ใช้เอง

## เปิดชุดที่ถูกต้อง

ขั้นตอน 3 มีช่อง **ชุดที่บันทึก** เลือกช่วง ID แล้วกด **เปิดชุดที่เลือก** โปรแกรมอ่านประวัติการบันทึกจริง เช่น `0021–0045` และ `0046–0070` พร้อมแสดงช่วงที่กำลังตรวจอย่างชัดเจน

**เปิดตารางนำเข้า MD** อ่านตารางที่คุณวางไว้เท่านั้น ไม่ได้หมายถึงชุดล่าสุดเสมอไป ชุดใหม่ใช้ปุ่มบันทึกภาพตรงในหน้า 2 ส่วน ZIP เก่าเปิดได้จาก **เพิ่มเติม → นำเข้า ZIP เก่า**

ชุดทดสอบใช้ข้อมูลจำลองแยกจากคลังที่คุณแก้จริง จึงไม่ยึดว่าคลังต้องมีภาพเพียง 20 คำอีก แต่ยังมีการตรวจข้อมูลจริงแยกต่างหาก


## หน้า 3: ภาพร่วมและแก้ข้อมูลต้นฉบับ

- แต่ละกรอบแสดงรูปหนึ่งครั้งทางซ้าย และคำทุกคำในชุดตรวจที่ใช้ ID เดียวกันทางขวา คลิกแถวเพื่อแก้คำนั้น เลื่อนเมาส์หรือใช้แถบเลื่อนเพื่อดูกรอบถัดไป
- คำที่นำเข้าจากคิวภาพร่วมใช้ความหมายของตนเองจากคลัง ไม่ใช้ความหมายของคำต้นทางหรือคำแปลที่แชทเสนอทับคำเดิม
- แก้คำศัพท์ ความหมาย ประโยค และคำแปลได้ พิมพ์คำตอบหรือเลือกข้อความในประโยคแล้วคำตอบในตารางจะเปลี่ยนทันที พร้อมสถานะยังไม่บันทึก การพิมพ์ประโยคไม่เติมคำตอบให้อัตโนมัติ
- แก้สะกดคำได้โดยยังอ้างอิงรายการต้นฉบับเดิม โปรแกรมป้องกันชื่อซ้ำและเปลี่ยนชื่อในคิวงานให้ด้วย ประวัติ SRS ในเบราว์เซอร์ยังอ้างอิงคำเก่า: คำที่เปลี่ยนชื่อจะเริ่มประวัติใหม่ โปรแกรมแจ้งก่อนบันทึกและไม่ลบประวัติเก่า
- เมื่อยืนยันบันทึกจะมีหลอดความคืบหน้า ตรวจข้อมูล → สำรอง → เขียนไฟล์ → อัปเดตหน้าจอ ระหว่างนี้กดบันทึกซ้ำหรือปิดหน้าต่างไม่ได้ หากเขียนไฟล์ล้มเหลวระบบคืนไฟล์ที่เขียนไปแล้วจากสำรอง


## เริ่มชุดใหม่หลังทำงานสำเร็จ

- หน้า 1: ส่งคำไป Cutter สำเร็จแล้วจะล้างโค้ดและพรอมป์ต์ กลับระดับเริ่มต้น แต่เก็บสำเนารายการที่ส่งไว้ตรวจลำดับภาพของชุดนั้น
- หน้า 2: รีเซ็ตภาพ รายการคำ และค่าตัดเป็น 5 × 5 / 256 พิกเซล หลังบันทึกภาพพร้อมชุดงานค้างและเปิดหน้า 3 สำเร็จ เลขเริ่มต้นใช้เลขถัดไป ไม่เปิดโฟลเดอร์อัตโนมัติ
- หน้า 3: หัวหน้าแสดงจำนวน “ยังไม่มีคำตอบ … ข้อ” และเปลี่ยนทันทีเมื่อแก้คำตอบ เลื่อนรายการได้จากทุกส่วนของหน้าหลักขณะอยู่แท็บ 3
- บันทึกทั้งชุดสำเร็จและอัปเดตคิวเสร็จแล้วจะล้างรายการกับช่องแก้ไข เปิดชุดที่บันทึกจากช่องประวัติได้ งานที่ยังต้องตรวจจะอยู่ในคิว การบันทึกแถวเดียวไม่ล้างแถวอื่น
- ยกเลิกหรือบันทึกผิดพลาดจะไม่รีเซ็ตหน้า 3 หน้าต่างความคืบหน้าอยู่กลางหน้าต่างโปรแกรมและล็อกการกดซ้ำจนจบ


## บันทึกภาพตรงและ ID ซ้ำ

ปุ่มหลักหน้า 2 บันทึกภาพตรงลง `visual/images` เท่านั้น ไม่ต้องจัดการไฟล์ตาราง หาก ID ชน จะแสดงภาพเดิม/ใหม่และคำที่ใช้ภาพเดิม:

- **ใช้เลขว่างชุดใหม่ (แนะนำ)** จัดเลขว่างต่อเนื่องให้ทั้งชุดและปรับรายการคำตามกัน
- **แทนที่เฉพาะภาพที่เลือก** สำรองก่อนเขียนและถามยืนยันอีกครั้ง ภาพชนที่ไม่เลือกจะได้รับเลขว่างใหม่ ทุกคำที่ใช้ ID ที่แทนที่จะเห็นภาพใหม่ ภาพชนิดอื่น เช่น PNG ต้องเลือกเลขใหม่เพื่อไม่เปลี่ยนชนิดไฟล์ของคำเดิม
- **ยกเลิก** ไม่เขียนภาพและไม่ล้างหน้า 2

คำที่มี imageId เดิมอยู่แล้วต้องใช้ ID เดิมหากต้องการเปลี่ยนภาพ โปรแกรมไม่ย้ายการผูกภาพเดิมไปอีก ID อัตโนมัติ

ภาพและชุดงานจะถูกบันทึกพร้อมบันทึกการเปลี่ยนแปลงใน `VocabularyStudio/data/image_backups` หากเขียนล้มเหลวจะคืนข้อมูลก่อนเริ่มชุด หากไฟดับระหว่างเขียน โปรแกรมตรวจและกู้คืนเมื่อเปิดใหม่ หากไฟล์ถูกแก้จากภายนอกจะหยุดแทนการย้อนทับงานใหม่

หลังบันทึกภาพแล้วสามารถปิดโปรแกรมได้: ชุดงานจะเปิดในหน้า 3 เมื่อเปิดใหม่ หรือกด **เปิดงานภาพค้าง** การปิดตามปกติจะเก็บค่าที่แก้ไว้ให้ด้วย หากแอปถูกบังคับปิด ชุดเริ่มต้นยังอยู่แต่ค่าที่เพิ่งพิมพ์อาจยังไม่ถูกเก็บ ต้องบันทึกชุดเดิมให้เสร็จก่อนส่งภาพชุดใหม่

เมื่อบันทึกคำศัพท์ทั้งชุดสำเร็จ โปรแกรมอัปเดตคิว ล้างหน้า 3 แล้วแสดง **เริ่มชุดใหม่ → หน้า 1** หรือ **ทำคิวงานต่อ → หน้า 4** งานที่ยังไม่ยืนยันคำตอบอยู่ในคิว การบันทึกแถวเดียวไม่เปิดหน้าต่างเลือกปลายทางและไม่ล้างแถวที่เหลือ

สำรองภาพแยกจากสำรองคำศัพท์: เมนูย้อนกลับชุดล่าสุดคืนการแก้คำศัพท์และคืนรายการงานค้างที่เกี่ยวข้อง ภาพที่บันทึกตรงก่อนหน้านั้นจะยังคงอยู่ในคลัง
